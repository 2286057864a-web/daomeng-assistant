# 源码运行与打包

当前桌面构建环境为 Windows、Python 3.13。运行前按 README 创建虚拟环境、安装依赖，并将 Android 官方 Platform Tools 解压为项目内的 `platform-tools/adb.exe`。

## 自检和测试

```powershell
.\.venv\Scripts\python.exe gui.py --selftest
.\.venv\Scripts\python.exe -B -m unittest discover -s tests
.\.venv\Scripts\python.exe -B verify_roster.py
.\.venv\Scripts\python.exe -B verify_fixes.py
```

`--selftest` 验证界面能初始化，正常输出 `SELFTEST OK`，不执行人员提交。程序正常启动时自动检测设备；自检启动阶段可能拉起 ADB server。回归脚本使用假设备和临时名单。

## 生成 Windows 程序

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm 到梦空间助手.spec
```

产物在 `dist/到梦空间助手/`。打包发布必须包含整个目录，特别是 `_internal` 内的运行库、图标及 ADB 资源。不要将开发机的 `out`、实际名单、诊断包或提交历史复制进发布目录。

## 主要文件

| 文件 | 用途 |
| --- | --- |
| gui.py | tkinter 窗口、任务队列、结果展示及致谢 |
| scan.py | 活动扫描和页面导航 |
| keyboard_search.py | 当前输入法搜索键识别及 Windows OCR 辅助 |
| makeup.py | 按年级补签 |
| roster_plan.py | 名单解析、计划和反馈表 |
| roster_workflow.py | 按名单的补签、录取和学分任务 |
| roster_device.py | 名单流程的手机页面操作 |
| device_checks.py / submission_log.py | 人数核对及提交记录 |
| work_report.py | 工作结果记录和 Excel 导出 |
| bootstrap.py / adb_boot.py | 运行资源及 ADB 启动 |
| errcatch.py | 异常记录和诊断导出 |

开发过程中保留业务方法接口。UI 使用标准库 tkinter/ttk，不引入第三方 UI 框架。
