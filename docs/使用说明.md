# 使用说明

## 连接手机

1. 手机开启开发者选项及 USB 调试。
2. 使用可传输数据的数据线连接电脑，在手机上确认调试授权。
3. 部分小米、红米设备还需要开启“USB 调试（安全设置）”。
4. 解锁手机，登录到梦空间中有管理权限的账号。
5. 打开助手，通过“重新检测设备”检查连接。

## 扫描和选择活动

点击“扫描活动列表”，在左侧选择要处理的活动。扫描沿列表顺序读取，到首个已完结活动结束；跳过的活动不会显示在操作列表中。手机已经在到梦空间时，无需人为退出后再开始。

## 补签

“按年级补签”和“按名单补签”是并列方式。

- 按年级：下拉选择年级或按实际年份填写，例如 `2027级`。点击“按年级勾选”，检查结果后再点击“提交补签（需确认）”。
- 按名单：选择 `.xlsx`，点击“按名单补签（需确认）”。

补签直接进入未签到列表。按年级扫描不会因为连续几屏没有目标年级就提前停止；连续三次下滑没有新人员才视为名单末尾。没有待处理对象时显示结果。

## 录取

选择报名中的活动，切到“录取”，导入名单。可以先演练，仅勾选而不提交；正式录取需要确认。处理随输入名单完成而结束。

## 学分

选择已结束的活动，切到“学分”，导入名单并填写本次分值。可以先演练，再确认正式发放。程序按名单进行身份匹配，不把同名人员直接视为同一个人。处理随输入名单完成而结束。

## 名单格式

使用 `.xlsx`，人员工作表的表头包含“姓名”和“学号”；按名单补签也可仅有“姓名”。学号建议在 Excel 中设为文本，填写完整 11 位数字。

| 姓名 | 学号 |
| --- | --- |
| 示例甲 | 20990000001 |
| 示例乙 | 20990000002 |

上表为虚构格式示例。实际读取以解析器校验为准；重复学号对应不同姓名等歧义会停止或提示处理，缺少学号的同名人员不会猜测身份。

## 工作结束及下一项任务

结束后右侧完成区显示本次工作结果，可以点击“导出工作名单”保存 Excel。等待日志恢复“已就绪”后，重新选择活动或名单，即可继续下一项任务，不需要退出助手。

工作记录在程序目录的 `out` 文件夹中。提交结果不明时先核对手机端和工作记录，避免重复提交。

## 反馈问题

点击“导出诊断包”保留现场信息。诊断内容可能包含设备信息、名单、日志及手机画面，请检查后再选择适合的渠道分享，公开 Issue 中不要附真实人员资料。

点击右下角“致谢”可查看项目主页。致谢窗口可收起或关闭，后台任务继续运行。
