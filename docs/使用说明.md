# 使用说明

## 连接手机

本程序通过 USB 调试模拟人工点击手机屏幕，运行时需要手机连接 Windows 电脑，可在手机上实时观察操作。

1. 手机开启开发者选项及 USB 调试，允许模拟点击。
2. 使用可传输数据的数据线连接电脑，在手机上确认调试授权。
3. 部分小米、红米设备还需要开启“USB 调试（安全设置）”。
4. 解锁手机，登录到梦空间中有管理权限的账号。
5. 打开助手，通过“重新检测设备”检查连接。打开到梦空间后扫描活动仍无反应时，先检查以上权限及数据线。

保持网络通畅，建议开启免打扰模式，使用全面屏手势操作及手机自带输入法。程序会保留当前输入法，但不同键盘布局仍需实际验证。任务运行期间请不要操作手机。HarmonyOS 和 iOS 尚未测试，不承诺支持。

## 扫描和选择活动

点击“扫描活动列表”，在左侧选择活动。扫描沿列表顺序读取，到首个已完结活动结束；跳过的活动不会显示。当前活动以深蓝底白字和“当前”标记突出显示。手机已经在到梦空间时，无需人为退出后再开始。

## 补签

“按年级补签”和“按名单补签”是并列方式。

- 按年级：下拉选择或按实际年份填写，例如 `2027级`。点击“按年级勾选”，完成后在手机核对人员并完成提交；界面相应按钮附有“请自行在手机上完成提交”提示。
- 按名单：选择 `.xlsx`，点击“按名单补签”。电脑确认框明确提示自动处理分组名单并提交，确认前务必核对活动和名单。

补签直接进入未签到列表。按年级扫描不会因为连续几屏没有目标年级就提前停止；连续三次下滑没有新人员才视为名单末尾。能够确认只有一屏的短名单直接读取。没有待处理对象时显示结果。

## 录取

选择报名中的活动，切到“录取”，导入名单。演练只勾选、不提交；正式任务在电脑确认后自动处理和提交。程序在报名页完成提交，不再逐人切换到录取页核查。工作表中的“已提交未核查”表示提交动作完成，仍需人工确认最终录取结果。

## 学分

选择已结束的活动，切到“学分”。

- 按年级：选择或填写年级，点击“按年级勾选”。完成后自行在手机核对人数、发分项目和分值并提交。
- 按名单：导入 `.xlsx`，填写本次统一分值。演练不发分；正式任务在电脑确认后自动处理和提交。工作表中的“已提交未核查”不代表已逐人核实到账。

名单流程先按姓氏分组搜索，再匹配完整姓名及名单中提供的学号。目标已在当前页时优先处理；短名单不为确认列表末尾反复滑动。可确认学号顺序时利用年级范围减少无效遍历，无法确认排序时保留完整扫描。

## 名单格式

使用 `.xlsx`，表头至少包含“姓名”；补签、录取和发分均可使用仅姓名名单。学号为可选字段，建议设为文本并填写完整学号。

| 姓名 | 学号（可选） |
| --- | --- |
| 示例甲 | 20990000001 |
| 示例乙 | 20990000002 |

上表为虚构示例。缺少学号且遇到同名歧义时跳过相关人员，在日志及工作结果中记录，不任意选择。重复学号对应不同姓名等格式冲突按解析器提示处理。

## 工作结束及下一项任务

右侧完成区显示本次工作结果，点击“导出工作名单”保存 Excel。表格上方保留任务汇总，下方仅列异常和未执行人员，不同类型使用不同颜色；正常完成人员不逐条列出。演练未提交、提交未核查及结果待核对均会保留提示。

等待任务结束、界面恢复可操作后，可重新选择活动或名单继续下一项任务，无需退出助手。工作记录保存在程序目录的 `out` 文件夹。正式任务结束后建议人工核验，仍有待提交步骤时自行在手机完成。提交结果不明时先核对手机端和工作记录，避免重复提交。

## 中断和反馈

运行中发现操作超出预期时，可使用停止按钮；紧急情况下可随时拔下 USB 数据线强制中断手机操作。若提交已经发出，断线不能撤销，请人工核对结果。

程序崩溃时，可关闭电脑端软件后重新运行。重启仍无法解决时，导出诊断包并发送至 `2286057864@qq.com`。诊断包可能包含设备信息、名单、日志及手机画面，请先检查内容，公开 Issue 中不要附真实人员资料。

点击右下角“致谢”可查看项目主页。Windows 可能对下载的软件显示安全提醒，本版本不承诺在所有电脑上免提示。
